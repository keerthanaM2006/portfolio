# Portfolio

My personal portfolio website, built during my web development internship.

## Live sections
- **Home** – introduction and quick links
- **About Me** – background and interests
- **Skills** – technologies I've learned
- **Contact** – contact details and a working contact form

## Built with
- HTML5
- CSS3 (Flexbox, Grid, responsive design, dark/light mode)
- JavaScript (mobile menu, theme toggle, scroll animations, form validation)

## Features
- Fully responsive for mobile, tablet and desktop
- Dark/Light mode toggle (remembers your choice)
- Smooth scrolling navigation
- Scroll-triggered animations
- Contact form with input validation
