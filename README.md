# Keerthana M — Portfolio Website

A responsive personal portfolio built from scratch with HTML, CSS and JavaScript, as part of a web development internship. Live at: **[keerthanaM2006.github.io/portfolio](https://keerthanaM2006.github.io/portfolio/)**

## Sections

| Section    | Description                                              |
|------------|------------------------------------------------------------|
| Home       | Introduction, resume download, and quick links            |
| About Me   | Background, education summary, and interests              |
| Skills     | Technologies I've learned, shown as a grid                |
| Projects   | Project cards with description and links                  |
| Education  | Timeline of my academic background                        |
| Contact    | Social links and a validated contact form                 |

## Features

- Fully responsive layout for mobile, tablet, and desktop
- Dark / light mode toggle, remembers the visitor's choice
- Smooth-scrolling navigation with a collapsible mobile menu
- Scroll-triggered animations (safely disabled if JavaScript fails to load, so content is never hidden)
- Contact form with client-side validation (name, email format, minimum message length)
- Downloadable resume (PDF)

## Built with

- **HTML5** — semantic structure
- **CSS3** — Flexbox, Grid, custom properties, responsive design
- **JavaScript (vanilla)** — no frameworks, no build tools

## Project structure

```
portfolio/
├── index.html      Page structure and content
├── style.css        All styling, responsive rules, dark mode
├── script.js         Interactivity: menu, theme, animations, form validation
├── resume.pdf        Downloadable resume
└── README.md          This file
```

## Running it locally

No build step or install required. Clone or download this repository, then open `index.html` directly in a browser.

```bash
git clone https://github.com/keerthanaM2006/portfolio.git
cd portfolio
```

Then double-click `index.html`, or open it with a tool like VS Code's Live Server extension.

## Deployment

This site is deployed with **GitHub Pages**, served directly from the `main` branch.
